# JobBridge — Project Proposal

## 1. Project Overview

JobBridge is a web-based job portal that connects job
seekers with recruiters through a centralized platform.

## 2. Problem Statement

Job seekers need a convenient way to discover relevant
jobs and track their applications. Recruiters need a
platform to publish jobs and manage applicants.

## 3. Project Objectives

- Build REST APIs using Java and Spring Boot.
- Implement authentication and authorization.
- Store application data in PostgreSQL.
- Develop a React frontend.
- Deploy the application to cloud hosting.

## 4. Target Users

- Candidate
- Recruiter
- Admin

## 5. Technology Stack

- Backend: Java, Spring Boot
- Database: PostgreSQL
- Frontend: React
- Security: Spring Security, JWT
- Testing: JUnit 5, Mockito
- API Documentation: Swagger / OpenAPI

## 6. Expected Outcome

A documented, tested, full-stack job portal with
a publicly accessible deployment.
